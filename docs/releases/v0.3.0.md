# v0.3.0 · 本地用户与器材训练 / Local users and equipment-aware training

[下载普通版 / Download regular APK](https://github.com/q1ngyang/open-mobifitness/releases/download/v0.3.0/OpenMOBI-0.3.0.apk) · [English](#english) · [验证范围](../V030_VALIDATION.md)

- 本地多用户：可选照片头像、个人外观／单位／指标／收藏／方案和身体参数；默认每次开始记录前确认身份，记录中与暂停时锁定用户。
- 用户可移除并保留历史；“移除用户并删除数据”需额外勾选不可恢复警示。旧记录保持未分配，可预览后认领；更正归属不改历史身份、参数与测量。
- 首页方案按可用空间显示一、二或三列。椭圆机、单车、划船机、跑步机使用对应编辑项，频率与心率可分别继承、独立设置或关闭。新增恢复／放松阶段默认关闭提示。
- 内置 70 个器材专属方案：椭圆机 21、单车 21、划船机 14、跑步机 14；[编排与来源](../BUILTIN_WORKOUTS.md)。运动界面宽屏同时显示六项指标，调阻与常用档位收紧排列。
- 运动指标放大字号，单位紧邻数值、基线对齐；按字体实测预留数字宽度，比例字体下读数更新也不频繁跳动。页码置于左右翻页按钮之间，圆点上下留白一致，常用档位保持单行。
- 记录页采用紧凑用户选择、默认周概览和器材筛选。报告按指标分组展示均值／极值和缺测信息，默认展示有效功率柱状图。悬浮窗标题展示用户名，未记录状态有独立提醒，阻力操作同排，高度随指标数量自适应。四色圆环加宽，位置保持原样。
- 完整备份包含所有用户、头像、个人设置、记录、方案与归属历史。旧备份可读；恢复默认不覆盖已有档案与个人设置。导出固定选择时的用户范围、语言与单位。
- Debug 内置四档案、六器材、36 个完整月份与边界案例，共 780 条演示记录；提供显式加载和精确清理，保护真实数据。普通版不包含该实现及专用文案。

本期不增加跳绳／哑铃分段编辑器、阶段达标率、跑步机电机或速度／坡度控制。跑步机目标仅作手动指导；器材调阻仍遵循既有能力与反馈边界。演示及模拟器结果不能代替真实蓝牙验证。

升级前可导出完整备份，然后直接覆盖安装同一类型的 APK，无需卸载。普通版与 Debug 分别沿用旧签名、数据互相独立。旧记录升级后显示为“历史未分配”，可在本机用户管理中预览后认领；旧方案与个人设置保留在“原有用户”。v0.3.0 新备份需要兼容的新版本读取。操作详情见 [使用变化](../V030_GUIDE.md)。

## English

[Download the regular APK](https://github.com/q1ngyang/open-mobifitness/releases/download/v0.3.0/OpenMOBI-0.3.0.apk). See the [validation record](../V030_VALIDATION.md#english) for build and testing scope.

Local profiles gain photo avatars and isolated preferences, plans, favorites and body parameters. New recordings confirm identity by default; active and paused sessions lock their user. Profile retirement preserves history, while data deletion requires an explicit warning acknowledgment. Legacy history stays unassigned until claimed; ownership correction preserves historical snapshots.

The home plan grid adapts to one, two or three columns. Elliptical, bike, rower and treadmill editors use compatible targets, with independent inherited/custom/off frequency and heart hints. New recovery/cooldown stages default to off. History opens to a compact weekly overview with equipment filtering. Reports group applicable measurements with their averages and extremes; available power is the default chart. Floating panels put the user in the title, distinguish unrecorded state, align resistance controls and adapt height to the selected readings. Brand rings become thicker without moving.

The built-in library contains 70 equipment-specific plans: 21 elliptical, 21 cycling, 14 rowing and 14 treadmill plans. Wide live dashboards show six readings, with compact resistance controls and responsive quick levels.

Larger readings and adjacent units share a baseline. Measured digit reservations prevent frequent unit movement even with proportional fonts. The page number sits between previous/next buttons, dots have balanced spacing and resistance presets stay on one row.

Full backups include all users, avatars, personal settings, recordings, plans and ownership history. Legacy formats remain readable; existing profile overwrite is off by default. Export freezes owner scope, language and units. Debug adds an explicitly loaded, precisely cleaned 780-record dataset covering four profiles, six equipment types and 36 complete months. Release excludes the dataset implementation and dedicated resources.

Dedicated jump-rope/dumbbell plan editors and stage attainment scores remain outside this version. No treadmill motor, speed or incline control is added. Simulation does not establish physical Bluetooth correctness.

Export a full backup before upgrading, then install the same app variant over the existing installation without uninstalling. Both variants preserve their previous signing keys and keep separate data. Legacy records remain unassigned until claimed in local user management; legacy plans and preferences belong to the original-user profile. New v0.3.0 backups require a compatible new app. See the [feature guide](../V030_GUIDE.md#english) for steps.
