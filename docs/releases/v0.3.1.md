# v0.3.1 · 退出入口、功率折线与方案排序 / Exit action, power lines and plan order

[下载普通版 / Download regular APK](https://github.com/q1ngyang/open-mobifitness/releases/download/v0.3.1/OpenMOBI-0.3.1.apk) · [English](#english)

- **仅控制模式可以直接退出**：底部固定显示红色描边“退出”按钮，位置与记录模式的“结束保存”一致。点击后断开器材及心率配件、关闭仅控制状态并回到首页，不生成运动记录。手机竖屏也会显示，关闭悬浮窗时仍保留。
- **功率恢复折线图**：记录详情默认优先展示有数据的功率，按时间连接同一有效数据段；缺测处断线，有效零值保留。点击读数仍显示实际采样时间与数值，均值、最大、最低和统计导出保持不变。
- **同类方案相邻、难度递进**：四类器材共用稳定的展示顺序，热身／恢复／放松相邻，轻度→中度→进阶、匀速 20→30 分钟、间歇 10→20→30 分钟、HIIT 入门→递进→长间歇连续排列。筛选保留相对顺序；方案 ID、收藏与训练内容不变。

Android 10+、64 位。普通版和 Debug 沿用各自原签名，可直接覆盖同类型旧版，无需卸载。数据库与备份格式沿用 v0.3.0。

验证包含 244 项单元测试、普通版与 Debug 的 Lint、同签名覆盖升级及数据内容比对、64 位库的 16 KiB 对齐。Android 14 原生界面回归覆盖手机横竖屏、平板横竖屏、折叠屏尺寸与 2 倍字体／深色主题，检查底部退出、服务停止、记录不增加、HIIT 相邻排列及功率折线的缺测、零值和点击读数。[实际界面截图](../SCREENSHOTS.md)。界面回归使用合成数据，不代表新的真实器材兼容性验证。

## English

- **Exit control-only mode directly:** a red outlined Exit button stays in the bottom dock, in the same position as Finish and save during recording. It disconnects equipment and the heart-rate accessory, leaves control-only mode and returns home without creating history. It remains available on portrait phones and when floating panels are disabled.
- **Power is a line chart again:** reports still prefer available power, connecting readings in time order within each valid segment. Missing intervals stay disconnected and measured zeros remain visible. Tapping shows the actual sample time/value; summary statistics and exports are unchanged.
- **Related plans stay together:** all four equipment libraries share a stable display order. Preparation/recovery, light-to-vigorous plans, steady-duration progressions, intervals and HIIT variants stay adjacent. Filtering preserves relative order. Plan IDs, favorites and workout targets are unchanged.

Android 10+, 64-bit. Both variants retain their signing keys and support installation over the same existing variant without uninstalling. Database and backup formats remain those of v0.3.0.

Validation includes 244 unit tests, Lint for both variants, same-key in-place upgrades with database-content comparison, and 16 KiB alignment of 64-bit libraries. Native Android 14 UI regressions cover portrait/landscape phones and tablets, foldable-sized windows, and 2× text with a dark theme. Checks exercise bottom Exit, service shutdown without adding history, adjacent HIIT cards, and power lines with missing intervals, zeros and selectable readings. See [actual captures](../SCREENSHOTS.md). Synthetic UI tests do not establish new physical-equipment compatibility.
