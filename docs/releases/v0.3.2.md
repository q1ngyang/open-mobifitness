# v0.3.2 · 清晰的运动表现与完成后返回首页 / Clearer performance and return home

[下载普通版 / Download regular APK](https://github.com/q1ngyang/open-mobifitness/releases/download/v0.3.2/OpenMOBI-0.3.2.apk) · [English](#english)

- **平均值更突出，分组更紧凑**：完成报告和历史训练详情中的运动表现使用清晰的指标行，平均值通过字号、字重和淡底色强调，最大／最低作为辅助信息。数字与单位相邻；浅色用深墨色数字，深色用近白色数字与低亮度蓝灰底。根据实际文字、单位、语言与系统字号测量可用空间，窄屏或大字号自然改为组内纵向排列。设备兼容性、有效指标、统计计算及导出不变，配速明确区分最快与最慢；功率折线图及其下方统计沿用原有样式。
- **保存后关闭报告回到首页**：方案训练和自由记录保存成功后结束当前运动模式，点击关闭、系统返回或手势返回均回到首页，不再自动进入仅控制。原有设备连接保留；从记录列表打开的详情仍返回记录列表。保存失败时保留当前记录及错误提示。

运动表现中的阻力以整数档位展示，旁边用浅色小字显示该档位对应的百分比，平均／最大／最低均适用。平均档位显示时四舍五入，百分比采用该次记录保存的设备最高档位，和训练界面一致；缺少档位范围的旧记录只显示档位，不推算百分比。原始统计及 CSV 保留原有精度。

Android 10+、64 位。普通版和 Debug 沿用各自原签名，可直接覆盖同类型旧版，无需卸载。数据库与备份格式保持不变。

## English

- **Compact groups with prominent averages:** the performance card in saved reports and history details uses aligned metric rows. Larger, heavier averages and a subtle background distinguish them from secondary extrema. Units sit beside values. Light mode uses dark neutral numbers; dark mode uses near-white numbers on a subdued blue-gray column. Actual text, units, language and system font size determine when a narrow card reflows into stacked groups. Compatible metrics, calculations and exports are unchanged; pace explicitly identifies fastest and slowest values. Power lines and the statistics beneath the chart keep their existing presentation.
- **Return home after saving:** finishing a planned or free recording ends its active mode. Closing the saved report through its Close action, system Back or a back gesture returns home instead of entering control-only mode. Existing device connections remain available. Reports opened from History still return to the history list. Failed saves retain the recording and error message.

Performance resistance values use integer levels with the corresponding percentage in smaller, secondary text for averages and extrema. Average levels are rounded for display; percentages use the maximum level archived with that recording, matching the workout screen. Legacy records without an archived range show levels without an inferred percentage. Stored statistics and CSV precision remain unchanged.

Android 10+, 64-bit. Both variants keep their original signing keys and support installation over the same existing variant without uninstalling. Database and backup formats are unchanged.
