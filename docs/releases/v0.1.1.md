# v0.1.1 · 首个正式版 / First stable release

[下载普通版 / Download regular APK](https://github.com/q1ngyang/open-mobifitness/releases/download/v0.1.1/OpenMOBI-0.1.1.apk) · [English](#english)

## 这版有什么？

OpenMOBI 可以不登录、不依赖原厂服务器，直接连接支持的器材开始运动。适用于 Android 10 及以上的 64 位手机和平板。

- **更实用的训练首页**：自由运动卡片显示连接状态，一键开始；今日时长、热量、次数和距离来自本机已保存的训练。粉、红、黄、蓝四色圆环与标题色条统一，浅深色图标保持已确认的设计。
- **更清楚的设备状态**：器材自带心率与独立心率设备分开说明。没有连接独立心率设备时，不再显示容易误解的“未连接”卡片。
- **统一的通知**：通知栏、通知列表和系统单色图标采用当前 Open／MOBI／FITNESS 标识；通知显示连接或运动状态，点击进入对应页面。
- **完整的离线训练**：21 套内置方案、搜索与收藏、自定义阶段、阻力滑块、指标自选和两级悬浮窗。
- **本地运动记录**：近期记录、年月查找、趋势与单次详情；统计 CSV 便于阅读，完整备份用于换设备。
- **更容易找到帮助**：README 精简为下载和主要功能，说明按主题分开。问题表单支持中英文，逐步引导导出蓝牙日志；开发试稿和调试记录留在本地。

标题色条与本版界面已在手机、平板及大字体窄屏截图中复核。[查看实际界面](../SCREENSHOTS.md)。

## 应该装哪个？

| 文件 | 用途 |
| --- | --- |
| `OpenMOBI-0.1.1.apk` | **普通用户选这个。** 不包含演示入口，可覆盖旧普通版，保留数据 |
| `OpenMOBI-0.1.1-debug.apk` | 测试用，包含演示设备；名称为 OpenMOBI Debug，与普通版共存，数据独立 |
| `OpenMOBI-0.1.1-SHA256SUMS.txt` | 安装包校验值，需要核对下载文件时使用 |

更新前可以在「设置 → 数据管理」导出完整备份。不要为了升级先卸载。普通版与 Debug 版不会自动迁移彼此的数据。

## 设备与数据说明

目前只有 V1 协议的 MB-EP 椭圆机有用户实机反馈；其他器材还需要逐型号验证。此版本不控制跑步机电机、速度或坡度。首次连接先看运动数据，再试相邻档位。异常请按[日志指引](../HELP.md)提交。

功率、热量或虚拟距离上的 `≈` 表示估算。已知 V1 使用复核后的官方旧版模型，没有任意降低功率，也没有为了达到方案热量目标抬高记录值。旧记录不重算；[算法说明](../ALGORITHM_AUDIT.md)列出来源与限制。

## English

### What's included?

OpenMOBI connects to supported equipment without an account or the original servers. It runs on 64-bit Android 10+ phones and tablets.

- **Useful workout home:** connection status and a start action, plus today's duration, energy, workout count and distance from saved local workouts. Solid pink/red/yellow/blue rings match the restored title accents. Approved light/dark app artwork is unchanged.
- **Clearer device status:** equipment-provided heart rate is distinct from a separate accessory. A disconnected accessory no longer leaves a misleading card.
- **Consistent notifications:** current Open/MOBI/FITNESS branding across notification and monochrome icons. Connection/workout status determines the label and tap destination.
- **Offline training:** 21 plans, search, favorites, custom stages, resistance slider, configurable metrics and two floating-panel sizes.
- **Local history:** recent records, year/month browsing, trends and individual details; readable CSV reports and full backups.
- **Easier help:** a shorter README and topic-based guides, bilingual issue forms with log instructions, and local-only development drafts/debug journals.

The restored title accents were visually checked on phone, tablet and enlarged-font narrow layouts. [View actual screens](../SCREENSHOTS.md).

### Which file should I install?

| File | Purpose |
| --- | --- |
| `OpenMOBI-0.1.1.apk` | **Choose this for everyday use.** No demo entry; installs over the previous regular app and keeps its data |
| `OpenMOBI-0.1.1-debug.apk` | Testing with simulated equipment; labeled OpenMOBI Debug, installed separately with independent data |
| `OpenMOBI-0.1.1-SHA256SUMS.txt` | Checksums for verifying downloaded APKs |

You can export a full backup from Settings → Data management before updating. Do not uninstall first. The regular and Debug apps do not automatically transfer data between each other.

### Equipment and estimates

Only V1 MB-EP ellipticals currently have user hardware feedback. Other equipment requires model-specific testing. This version does not control treadmill motors, speed or incline. Check readings and a one-level resistance change on first connection; use the [log guide](../HELP.md#english) if something fails.

`≈` marks estimated power, energy or virtual distance. Known V1 uses the reviewed original model without an arbitrary power reduction or inflated energy to match plan targets. Old records are not recalculated. See [calculations and limits](../ALGORITHM_AUDIT.md#english).

### Release checks

- 32 core, 27 Debug app and 28 Release app unit tests passed, along with both Android Lint variants and 344 resource keys across six languages.
- Android 14 emulator checks covered phone/tablet orientations, unfolded-sized windows and narrow dark layouts with enlarged fonts. The restored title accents were rechecked on phone, landscape tablet and narrow German layouts.
- The final build rechecked the library, history/details, post-save result, and six-language workout switching while preserving the same workout.
- An alpha.7 in-place upgrade with the existing signing key preserved test sessions, samples, custom plans, preferences and first-install information.
- Regular/Debug package identities, signatures, 64-bit ABIs and APK/native-library 16 KiB alignment were verified.
- No new physical equipment or actual foldable-device testing was performed in this round. Emulator success does not establish compatibility with other equipment.
