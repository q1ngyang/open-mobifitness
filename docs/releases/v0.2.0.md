# v0.2.0 · 想练就练，想记再记 / Work out, record when ready

[下载普通版 / Download regular APK](https://github.com/q1ngyang/open-mobifitness/releases/download/v0.2.0/OpenMOBI-0.2.0.apk) · [English](#english)

## 这版有什么？

- **不记记录也能练**：新增「仅控制」，连接后就能看数据、调阻和使用悬浮窗。需要时再开始记录，保存后回到仅控制，不用重新连接。
- **常用操作更顺手**：记住常用设备、设备备注和每台器材的四个快捷档位。悬浮窗保留摆放位置，小窗看数据，展开后可调阻、暂停或回到应用。
- **界面更紧凑**：首页四项今日统计恢复单行，运动数字与单位更清楚。手机横屏减少顶部和底部留白，兼顾平板、分屏及大字体。
- **按自己的节奏运动**：可手动设置频率或心率范围，按需开启声音、震动提示；默认关闭，不会自动调阻。
- **连接和备份更可靠**：整合器材协议与指标筛选，断线重连后由你决定何时继续记录。较大的运动备份也能导入，可选择一并恢复哪些设置。

## 怎么升级？

日常使用下载 `OpenMOBI-0.2.0.apk`，直接覆盖原普通版，**不要先卸载**。测试用的 `OpenMOBI-0.2.0-debug.apk` 与普通版数据独立；两版仍使用原签名。需要校验下载文件时使用 `OpenMOBI-0.2.0-SHA256SUMS.txt`。

建议先在「设置 → 数据管理」导出完整备份。旧记录和旧备份继续可用，具体操作见[开始使用](../USER_GUIDE.md)。

## 使用与验证说明

目前 V1 MB-EP 椭圆机有用户实机反馈，其他型号通过协议对照和模拟测试，尚无实机反馈。本版不控制跑步机电机、速度或坡度；暂停或结束记录也不等于停止器材。

Android 10 和 Android 14 已完成界面操作检查。Android 17 的界面验证因模拟器系统故障未完成，**不代表已确认无法运行**。构建、旧数据升级、大备份及屏幕适配的详细结果见[验证记录](../V020_VALIDATION.md)。蓝牙异常请按[反馈指引](../HELP.md)导出日志。

## English

### What's new?

- **Work out without saving a record:** control-only mode shows readings, adjusts resistance and supports floating panels. Start recording when ready; saving returns to control only without reconnecting.
- **Fewer repeated steps:** saved devices, notes, four resistance presets per machine and remembered panel positions. Use the small panel for readings or expand it to adjust resistance, pause and return to the app.
- **Compact screens:** one row of daily totals, clearer values and units, and less header/footer space in phone landscape. Tablet, split-screen and large-text layouts are improved too.
- **Your own optional hints:** manually set frequency or heart-rate bounds with optional sound or vibration. Hints are off by default and never change resistance.
- **More reliable connections and backups:** integrated equipment protocols and metric filtering, explicit resume after reconnecting, and larger backups with selectable settings to restore.

### Updating and using the app

For everyday use, install `OpenMOBI-0.2.0.apk` over the regular app. **Do not uninstall first.** `OpenMOBI-0.2.0-debug.apk` is for testing and keeps separate data. Both retain their original signing keys. Checksums are in `OpenMOBI-0.2.0-SHA256SUMS.txt`.

Export a full backup in Settings → Data management before updating. Existing records and older backups remain supported. See [getting started](../USER_GUIDE.md#english).

User hardware feedback covers V1 MB-EP ellipticals; other models have protocol and simulated checks, not hardware feedback. Treadmill motor, speed and incline controls are not provided. Pausing or finishing a record does not stop the machine.

UI interactions were checked on Android 10 and 14. Android 17 UI checks were blocked by emulator system failures; **this does not establish that the app cannot run there**. See the [validation record](../V020_VALIDATION.md#english) for build, upgrade, backup and layout checks, and the [feedback guide](../HELP.md#english) for Bluetooth logs.
