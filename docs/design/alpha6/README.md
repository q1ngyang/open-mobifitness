# 方案库与运动记录设计（alpha.6）

先通过内置 imagegen 工具生成四张设计稿，再用原生 Compose 实现交互。
完整原始提示词见 [prompts.txt](prompts.txt)。设计稿为示例数据，不代表实机采集结果。

- [训练返回入口](active-workout.png)：整块可点的蓝色提示条，计时、训练状态、设备／阶段和明确的“返回训练”操作。
- [方案库](library.png)：搜索、时长／最高阻力／来源筛选；收藏置顶；我的训练和内置方案分组，可展开／收起。实现去掉示意图的照片和额外导航。
- [记录概览](history.png)：周／月／年／全部统计，时长柱图，可点击查看数值；紧凑设备标签列表；日期切换、搜索、设备／数据来源／归档筛选和分页。手机默认折叠趋势图，保留三项合计并优先露出列表；宽屏分栏默认展开。
- [单次详情](detail.png)：总量、平均／峰值、五类数据曲线、来源与采样质量；导出、可恢复归档；删除放到菜单内并确认。图中私有生理模型不纳入实现。

## 数据与操作约定

- 百分比采用官方 MotionData 的 `round(level / maximum * 100)`，目标百分比按最大档位换算后取最近的设备支持档位。24 档设备：1 档 4%，12 档 50%，24 档 100%。最低档保护依旧保留。
- 对照国际版 `MotionData`、`EllipticalWorkoutFragment`，中国版 `MotionData`、`CreateWorkoutActivity`。两版舍入方法分别落到 `Math.round`。本仓库仅记录公式和定位，不发布反编译源码。
- 百分比指设备档位比例，不等于个体运动强度。筛选中的高／中／低表示方案最高阻力目标。
- 统计只取已保存的训练；进行中的训练通过返回入口查看。演示数据单独标注，可筛选。
- 归档不删除数据、不影响统计；可单条恢复。批量归档只作用于当前筛选范围，执行前显示数量并确认。
- 详情返回保留列表滚动位置；分页与搜索条件在界面重建后保留。已确认的保存操作不随列表项移出视野而取消。
- 列表每页 20 条；数据库按时间、归档和设备类型建立索引。保存实时样本时不刷新全部记录列表。详情仅查询一个训练的样本，曲线保留端点与桶内极值，最多 240 个点。
- 采样平均按有效运动时间加权；读数最多覆盖之前 5 秒，不填补长时间中断。缺少传感器时显示破折号。旧数据不会凭空补造心率、功率或训练效果。
- 统计 CSV 每次训练一行，包含本地日期及 UTC 偏移、设备、方案、时长、距离／热量、平均／峰值、步数／桨数、估算来源、演示标记、状态和归档信息。UTF-8 BOM，含单位、公式转义，可直接用表格软件打开。
- 完整备份 ZIP 保留原始 CSV 用于导入和迁移。数据库升级为 v4，兼容数据库 v1–v3 和旧备份。收藏属于本机界面偏好。
- 蓝牙协议报文默认开启；保留用户明确关闭的设置。日志仍采用 32 KiB／30 分钟的独立报文容量及自动清理，不自动上传。
