# v0.1.1 V1 椭圆机兼容性复核

[完整协议验证](PROTOCOL_VERIFICATION.md) · [可重现对照工具](../tools/protocol-oracle/README.md)

结论：在已实测 MB-EP／V1 椭圆机的协议路径上，未发现本轮实现破坏 v0.1.1 兼容性的差异。已完成两版官方 APK 的实时训练协议适配、代码与本地验证，并以 v0.1.1 发布包和既有实机日志补充回归，可以宣告本阶段初步完成。其他型号无需再提供实机作为本阶段的验收条件。

本轮没有新连接实体器材；“V1 验证”指**用户确认可用的 v0.1.1 基线、历史实机帧回放和模拟 GATT 控制闭环**，不是一次新执行的无线连接或机械调阻实验。

## 基线与输入

- 发布标签：`v0.1.1`，提交 `78b3c27a434eec5bc5cdb807be967328df352660`。
- 直接执行该版本 Debug APK 的原 DEX；SHA-256：`441a564b7e879f76813de6cf806d5f3b0b5bfca2a17910d83a6c5f73e74ed950`。没有用重写的旧公式冒充旧版结果。
- 本地历史 MB-EP 日志：394 条 15 字节实机状态帧；原始运动／心率信息不进入仓库。它们来自较早的硬件反馈，沿用到了 v0.1.1 协议实现；不把日志的采集版本误称为 v0.1.1。
- 公开合成回归：576 组，覆盖 1–24 档、静止与不同脉冲间隔、4 种配置字节；期望表来自 v0.1.1 APK。
- 官方对照：国际版 2.1.14、中国版 4.5.16.1 均接收相同的历史帧；两版回调结果一致。

## 逐项对比

| 项目 | v0.1.1 与当前实现 |
| --- | --- |
| 设备与服务 | `MB-EP`、FFE0、FFE4 通知、FFE3 写入，保持一致 |
| 状态识别 | `AB 04`，类别 `0B`、子型 `11`；不是 AC，保持一致 |
| 当前档位与范围 | 字节 13 为反馈；1–24 档可读写，保持一致。3 条初始零档位仍不伪造为实际反馈 |
| 频率 | 大端字节 7–10 为间隔，0B11 每圈双脉冲；394 帧均与旧版一致 |
| 心率 | 字节 14；历史帧的有效值及缺失值与旧版一致 |
| 调阻编码 | `AB 03 00 previous[3] previous[4] level previous[6]`；每帧逐一比较全部 24 档，9,456 次字节比较一致；公开合成集另比较 13,824 次 |
| 功率 | 相同频率与稳定反馈档位，整数显示和未截断热量输入均与旧版一致；沿用 0B11 的 1.5 系数 |
| 档位变化时的计算 | 当前按官方每个有效秒最多追近 2 档的计算阻力过渡；旧版直接使用反馈。显示档位始终是实际反馈，这项变化影响瞬时估算，不改变调阻字节 |
| 初始化 | 新增官方 MTU 128 和操作间隔 300 ms；MTU 被拒绝时仍可订阅、收数、调阻。V1 椭圆机没有新增解锁或周期控制帧 |
| 训练开始／暂停／结束 | V1 椭圆机仍只控制本地记录状态，不发送 V2／FTMS 生命周期命令 |
| 回调与重连 | 保留新旧 Android 通知入口；以设备反馈确认调阻；旧连接回调和未完成请求不能污染新连接 |

两版官方 APK 对历史日志输出 391 个有效阻力、377 个频率回调，共 768 个字段，与 v0.1.1 及当前实现一致。官方静止帧通过 Ping 事件处理；OpenMOBI 直接发布零频率以清除过期运动值。

异常输入上的已有差异也已明确：官方对超出有效频率区间的值会回退到默认频率，当前遵循该规则；独立心率服务保持标准小端；不复制越界读取、未知控制能力猜测或数值回绕。历史实机帧没有触发这些差异。

## 本次审查补齐的兼容点

1. 多特征 V2 设备初始化不再受发现阶段的总超时提前中断；每个 GATT 操作仍各自计时。
2. 旧划船机截断报文在改写型号／模板之前被拒绝，避免破坏已有椭圆机控制状态。
3. V1 折叠跑步机的首次状态查询、AE 折叠反馈、错误码和设备时长；V2 速度／坡度能力、折叠、急停、小器材交互，以及原始按键／语音事件值。
4. FTMS 完整处理器中的二次转换：划船速度取整，阻力／坡度整数化，跑步频率／步幅、设备时长；缺少功率时接入官方计算阻力及估算模型。另恢复速度／坡度范围与机器停止／暂停／启动状态。
5. 按器材类型筛选和独立保存训练页、两种悬浮窗的指标设置，椭圆机不会出现划船机或跑步机专属指标。

完整验证数量、工具入口与代码边界统一记录在[协议验证说明](PROTOCOL_VERIFICATION.md)。结论覆盖参考 APK 中已恢复的实时训练支持及 V1 已有实机基线；不是对未见固件、所有 Android 蓝牙栈或机械功率标定的无条件保证。本阶段没有依赖其他型号实机的未完成验收项。
