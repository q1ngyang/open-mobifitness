# 数据与网络

训练和器材信息保存在应用私有 Room 数据库内。无需账号，无广告、统计、推送、厂商登录 SDK，不向原厂服务器注册器材。

应用仅在用户点击检查更新或打开仓库链接时使用 GitHub。GitHub 会收到常规网络请求信息；不会上传运动记录或设备标识。更新检查不需要嵌入访问令牌，失败不影响本地训练。

CSV／备份由用户通过系统文件选择器选择位置。诊断导出包含 GATT 服务、特征、能力、型号／固件和错误，默认不包含蓝牙地址、序列号及运动采样；主动开启的协议报文可能包含传感器读数。不要在诊断中追加个人信息后无意公开。

关闭系统云备份，使用显式文件备份。卸载会清除应用私有数据，应先导出需要保留的记录。

附近设备权限用于 BLE。Android 10–11 的蓝牙搜索受系统位置权限和定位开关约束，应用不采集地理位置。悬浮权限只用于用户主动打开的运动控制面板；不读取其他应用画面。通知用于器材连接服务；实际训练期间的有界 CPU 唤醒锁用于保持计时和课程调度。

## alpha.2 诊断日志

应用仅在本机保存近期事件、连接能力、错误类型与有限的异常堆栈，约 512 KiB 轮换。导出的日志包含 App 版本、Android API、手机厂商及型号，用于复现兼容问题。默认不包含蓝牙 MAC、序列号、设备名称、训练历史或 CSV 样本。蓝牙地址会做文本脱敏。

「记录蓝牙协议报文」默认关闭；开启后记录限定传感器／控制特征的有限长度报文，可能含实时运动与心率读数。它用于由用户主动提交的器材兼容问题，不采集系统 logcat。所有导出均通过 Android 文件选择器交给用户保管，不会自动创建 issue 或上传日志。体重与 MET 参数仅保存在本机，并随用户主动导出的训练备份保存。
