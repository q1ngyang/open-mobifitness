# 数据与网络

训练和器材信息保存在应用私有 Room 数据库内。无需账号，无广告、统计、推送、厂商登录 SDK，不向原厂服务器注册器材。

应用在用户点击检查更新、项目主页或问题反馈时访问 GitHub；作者链接会打开 X。GitHub 会收到常规网络请求信息；不会上传运动记录或设备标识。更新检查不需要嵌入访问令牌，失败不影响本地训练。

CSV／备份由用户通过系统文件选择器选择位置。诊断导出包含 GATT 服务、特征、能力、型号／固件和错误，不包含完整训练历史或蓝牙地址；默认开启的协议报文可能包含实时运动及心率读数。不要在诊断中追加个人信息后无意公开。

关闭系统云备份，使用显式文件备份。卸载会清除应用私有数据，应先导出需要保留的记录。

附近设备权限用于 BLE。Android 10–11 的蓝牙搜索受系统位置权限和定位开关约束，应用不采集地理位置。悬浮权限仅用于运动控制面板；开启自动悬浮后，切换应用会自动显示，可在设置关闭；不读取其他应用画面。通知用于器材连接服务；实际训练期间的有界 CPU 唤醒锁用于保持计时和课程调度。

## 诊断日志（alpha.4 / report 4）

事件文件最多 64 KiB、保留 48 小时；协议报文最多 32 KiB、保留 30 分钟。启动写入或导出时自动清理过期内容，升级时也会清理旧轮换文件。导出仅含近 24 小时事件与近 30 分钟协议报文，总大小低于 128 KiB。高频报文使用独立容量，不会挤掉连接／控制错误。设置中的「清除诊断日志」只清除日志，不删除训练记录。

导出包含订阅状态、接收／解析计数、最近报文距今时间、控制反馈超时标记、App 版本、Android API、手机厂商及型号。默认不包含蓝牙 MAC、序列号、设备名称、训练历史或 CSV 样本。蓝牙地址做文本脱敏。

从 alpha.6 开始，「记录蓝牙协议报文」默认开启（保留用户已明确关闭的选择）；记录限定传感器／控制特征的有限长度报文，可能含实时运动与心率读数。不采集系统 logcat。关闭开关停止新增报文，已有报文在到期或主动清除后删除。所有导出均通过 Android 文件选择器交给用户，不会自动创建 issue 或上传。体重与 MET 参数仅保存在本机，并随用户主动导出的训练备份保存。
